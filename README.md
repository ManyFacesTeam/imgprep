# ManyFace Image Prep

00-prep.qmd processes the raw images and adds Face++ alignment templates. The std_neu_0 set are saved in manyfaces/small, but the rest are only on Lisa's computer for now (they are too big to share on github)

01-align.qmd processes the small images to test different alignment techniques. Red fill is used to highlight where each technique requires filled background (it will be replaced with white or image-specific background colour later).
